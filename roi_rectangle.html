class roi_rectangle.RoiRectangle(y1: int, y2: int | None, x1: int, x2: int | None)¶

Bases: object

A rectangular region of interest.

Intervals are half-open: rows [y1, y2) and columns [x1, x2), so y2 and x2 are not part of the region.

Args:

y1 (int): First row. y2 (int | None): End row (exclusive). None extends the region to the

end of the axis.

x1 (int): First column. x2 (int | None): End column (exclusive). None extends the region to

the end of the axis.

Number of pixels in the ROI, or None if an axis is unbounded.
